操作性を改善するため、UIを一から再構築しました。あわせてメインアプリとリモコンアプリで共有するデザインシステムを新設しています。

## 主な変更

### 共通デザインシステム(`:ui` 新設)
- `:app` と `:remote` が共通モジュール `:ui` を参照(Material 3テーマ + 共通コンポーネント)
- **システムのライト/ダーク設定に追従**(`values` / `values-night`)。
- 出力モード(LIVE=青 / FREEZE=橙 / PRIVACY=紫)・健全性・警告を意味色として体系化し、両テーマで視認できる配色に。

### メイン画面
- LIVE / FREEZE / PRIVACY を**大きなボタン**として配置(仕様7.4)。PRIVACYは常時実行可能。
- プレビューを覆っていたステータス表示を整理し、オーバーレイ(モード・トラッキング)と下部の統計行(LOD / FPS / 推論 / 温度 / 録画 / 配信 / アバター)に分離。
- カメラのバインド失敗時に**再試行UI**を表示。エラーはSnackbarで通知。
- BLE認証コードのコピー、アバター未設定時の設定への導線を追加。

### 設定画面
- トピック別のカード化(カメラ / トラッキング / アバター / プライバシー / 録画・配信 / Bluetooth)。
- アバター削除の**確認ダイアログ**、ストリームキーの**マスク表示(表示切替)とURLとの分離保存**、保存時のフィードバック。
- アバターサイズをチップからスライダーに変更。

### 録画一覧
- 明示的な**再読み込み**、削除の**確認ダイアログ**、空状態の案内を追加。

### リモコンアプリ
- 接続 / 認証 / 出力モード / 録画・配信 / 状態をカード化。
- FREEZE・PRIVACYを大きく分離配置(仕様10.2)。

## 安全性(変更なし)
- 異常時の出力は合成フレーム / 凍結フレーム / PRIVACY画像の3択のみ。
- FREEZE・PRIVACYからの復帰はユーザー操作必須(0.5秒以上の連続正常判定でLIVEボタンを有効化)。
- UIの再描画はカメラ・推論・エンコード処理に影響しません(プレビューは専用GLスレッド)。

## 確認事項(実機未検証)
- ライト/ダーク双方での視認性・操作性の実機確認は未実施です(CIでのビルド・単体テストのみ)。

## インストール
- メイン端末: `ZisshaVR-v0.1.2.apk`
- リモコン端末: `ZisshaVR-Remote-v0.1.2.apk`(任意)
