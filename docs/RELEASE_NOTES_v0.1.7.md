アバターの追従座標系を全面的に見直し、あわせて表示・安全動作を改善しました。

## 主な変更

### 1. アバターの向き・位置・サイズ(座標系の修正)
- **向き**: 四肢・頭・胴の方向を、**表示映像と同一の正規化画像座標**(x右・y下)から算出するように変更しました。MediaPipeのワールド座標の軸方向に依存しなくなり、**映像のシルエットに一致**します(奥行きのみワールド座標のzを使用)。
- **位置・サイズ**: アバターの**腰を検出した腰に一致**させ、**肩幅比でスケール**する方式に変更しました。スケールは腰を中心に適用し(スキン後にモデル変換として適用)、従来の「上に浮く/サイズが合わない」問題を解消します。
- 可視性の低いランドマークは使わず、その部位はニュートラル姿勢を保ちます。

### 2. 身体の一部しか映らない時の破綻を軽減
- 腰・肩が検出できている時だけ位置/スケールを更新し、それ以外は直前の値を保持。
- 髪・スカート(SpringBone)が破綻しないよう、骨の頭が大きく跳んだ場合はテールを再シードし、速度をクランプ。**メッシュが飛散する症状**を防止。

### 3. MediaPipeの骨格を映像に合成
- 検出した33ランドマークの骨格を映像に重ねて表示します(設定 → トラッキング → 「骨格を重ねて表示」、既定ON)。**検出位置とアバターのズレを目で確認**できます。

### 4. カメラ映像のアスペクト比を維持
- プレビューは映像を引き伸ばさず、**元のアスペクト比を維持**して表示します(余白は黒帯)。

### 5. 自動復帰(設定)
- 自動で **FREEZE / PRIVACY** になった後、トラッキングが0.5秒安定したら**自動でLIVEへ復帰**します(設定 → 安全 → 「自動で復帰」、既定ON)。
- 安全のため、**ユーザーが明示的に選んだ**場合は自動復帰の対象外です(自動発動時のみ)。

## 確認事項(実機未検証)
- 変更はコード解析に基づく修正です。座標系は今回のように画像基準に寄せていますが、端末・環境で向きが残る場合は「骨格を重ねて表示」で検出位置を確認しつつ、設定の「向き(回転)」「ミラーを反転」も併用してください。
