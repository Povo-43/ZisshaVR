3つの問題を修正しました。

## 修正内容

### 1. アバターの半透明化を修正
- アバターシェーダーを直行alpha（straight alpha）から**乗算済みalpha（premultiplied alpha）**出力に変更
- RGB値をalphaで乗算して出力するようにし、合成パスのブレンド（`ONE, ONE_MINUS_SRC_ALPHA`）と整合
- これにより人物マスク領域で正しく不透明に表示されるように

### 2. アバターが画面中央で固定される問題を修正
- ルート初期化のフォールバック連鎖を強化：
  1. 腰(hips)が見える → 位置初期化
  2. 肩(shoulders)が見える → スケール初期化
  3. 鼻(nose, idx 0)が見える → 位置・スケール初期化（腰の推定位置）
  4. 首(neck, idx 1)が見える → 位置・スケール初期化
  5. 任意の可視ランドマーク → 位置・スケール初期化（最終手段）
- これにより部分的な検出でも即座に追従を開始

### 3. フェイストラッキングが動作しない問題を修正
- `LodController`の初期化で`faceEnabled = true`に設定（従来は`update()`が呼ばれるまで`false`）
- コンストラクタで`applyConfig()`を呼ぶようにし、起動直後から顔検出が有効に
- `lastChangeMs`フィールドを追加（未初期化によるクラッシュ防止）

## 期待される動作
- アバターが不透明に表示され、人物マスク内で正しく重なる
- 人物が画面に入った瞬間から位置・サイズが追従（上半身のみでも鼻/首から推定）
- 表情（瞬き、口の開閉、眉の動き等）がアバターに反映される
