## 変更内容

### 顔の向き修正
- 頭部の右ベクトル計算を `left_eye - right_eye` → `right_eye - left_eye` に変更
- ミラー映像では左目(インデックス2)が画面右、右目(インデックス5)が画面左に見えるため、アバターの右ベクトル(解剖学的右)は `right_eye - left_eye` で求めるのが正しい
- これにより頭部の前方向が +Z → -Z (ビュー空間) に反転し、顔が正面を向くようになった

## 既知の課題
- アバターサイズの自動合わせ込みは肩幅ベースで推定しています。実機で「設定 → アバター → スケール調整」で微調整してください
- VRM 0.x/1.0 双方で正面が映り、腕の左右が合っているか要確認
