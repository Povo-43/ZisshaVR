プレビューが真っ黒でカメラ映像が表示されない問題を修正しました。原因はGL側の3件のバグです。

## 修正

### 1. プレビューが恒久的に真っ黒(カメラ映像が出ない)
- `GLRenderer.setPreviewSurface` が、UIから渡されるたびに**SurfaceHolderが所有するSurfaceを `release()`** していました。
- `surfaceCreated` の直後に `surfaceChanged` が同じSurfaceを渡すため、2回目の時点でSurfaceが解放され、プレビュー用EGLサーフェスを作れなくなっていました(FPS・トラッキングは別経路で動き続けるため「正常」に見えます)。
- 修正: プレビューSurfaceはSurfaceViewが所有するため**解放しない**。同一Surfaceの再通知は**何もしない**。GL初期化前にSurfaceが来た場合は**初期化後に適用**するよう変更。

### 2. FREEZE / PRIVACY が出力に反映されない
- `glRenderer.gateMode` が初期値(LIVE)から一度も更新されておらず、安全ゲートの出力選択(合成 / 凍結フレーム / プライバシー画像、仕様7)がGLレンダラに伝わっていませんでした。
- 修正: セーフティゲートのモード変更をレンダラへ同期。

### 3. アバターが原点に潰れる
- スキニングのボーン行列を、**行列を充填する前にGPUへアップロード**していたため、常にゼロ行列でスキニングされ、全頂点が原点に縮退していました。
- 修正: 行列充填→アップロードの順に変更。

## UI
- メイン画面の状態表示に**描画FPS(合成出力のフレームレート)**を追加。推定FPS(トラッキング)と分けて確認できます。

## 確認事項(実機未検証)
- 上記はコード解析に基づく修正で、実機での動作確認は未実施です。
- プレビューが出ない場合は、起動直後のログで `GLRenderer: preview EGL surface ready / unavailable` を確認してください。
