録画ボタンが機能しない問題を修正しました。

## 原因
- RootEncoder の `startRecord` は、映像入力を `NoVideoSource`(自前のSurfaceTextureで合成フレームを流し込む方式)にしている場合、**既定で「音声のみ(AUDIO)」トラックを選択**します。そのため録画を開始しても**映像トラックが一切書き込まれず**、録画が機能していませんでした。
- また、録画/配信の開始に失敗しても**画面に何も表示されず**、反応していないように見えていました。

## 修正
- 録画トラックを**明示的に指定**(音声ありなら `ALL`、音声なしなら `VIDEO`)し、合成映像がMP4に書き込まれるようにしました。
- 録画セッションは**毎回クリーンに作成**するようにし(配信中のみ既存セッションを再利用)、停止済みの古いセッションに `startRecord` して無言で失敗する経路を排除しました。
- 録画/配信の**開始失敗をSnackbarで通知**するようにしました(例: 「録画を開始できませんでした(保存先とコーデック設定を確認してください)」「RTMP URLが未設定です」)。

## 確認事項(実機未検証)
- 変更はコード解析(RootEncoder 2.8.2 のソース確認)に基づく修正で、実機での録画ファイル確認は未実施です。
- 録画ファイルは `Movies/ZisshaVR` にも登録されます(アプリ内「録画一覧」から共有/削除できます)。
