透過・固定位置・フェイストラッキングの3問題を修正しました。

## 修正内容

### 1. アバターの半透明化を修正
- アバターシェーダーを乗算済みalpha（premultiplied alpha）出力に変更（RGB × alpha）
- 合成シェーダー `MASKED_OVER_FS` でマスク適用時に **RGBとalpha両方** をスケールするよう修正
- 従来はalphaのみマスクしていたため、マスク領域でRGBが明るすぎて半透明に見えていた

### 2. アバターが画面中央で固定される問題を修正
- ルート初期化のフォールバック連鎖：腰 → 肩 → 鼻 → 首 → 任意のランドマーク
- **初回の腰検出時に即座に位置をスナップ**（スムージングをスキップ）
- 鼻/首フォールバックから初期化された後、腰が検出された瞬間に正しい位置へジャンプ

### 3. フェイストラッキングが動作しない問題を修正
- `LodController` で `faceEnabled = true` をデフォルトに（従来は `update()` 呼び出しまで false）
- コンストラクタで `applyConfig()` 呼び出し、起動直後から顔検出有効
- `lastChangeMs` フィールド追加（未初期化クラッシュ防止）

## 期待される動作
- アバターが不透明に表示され、人物マスク内で正しく重なる
- 人物が画面に入った瞬間から位置・サイズが追従（上半身のみでも鼻/首から推定）
- 腰が検出され次第、即座に正しい位置へ移動
- 表情（瞬き、口の開閉、眉の動き等）がアバターに反映
