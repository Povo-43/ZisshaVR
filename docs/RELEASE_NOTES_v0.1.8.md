横向き・ミラー表示時のカメラ映像とトラッキング座標の整合性を修正しました。

## 主な変更

### 1. 骨格オーバーレイのズレを修正（横向き・ミラー対応）
- カメラ画像を回転／ミラー表示している端末で、**緑の骨格オーバーレイが実写とずれる**問題を修正。
- カメラのセンサー回転（0/90/180/270度）、左右ミラー、およびプレビューのアスペクト比維持（レターボックス）をすべて考慮して、MediaPipeの検出座標を映像上に正しく重ねるように変更。
- 設定 → カメラ → 「向き(回転)」と「ミラーを反転」の組み合わせと、オーバーレイが自動で連携します。

### 2. その他 v0.1.7 からの継続改善
- 骨格オーバーレイ表示（設定 → トラッキング → 「骨格を重ねて表示」、既定ON）
- カメラ映像の元のアスペクト比維持（引き伸ばしなし）
- 自動復帰（自動発動の FREEZE/PRIVACY から安定後に自動で LIVE へ、設定 → 安全 → 「自動で復帰」、既定ON）
- 身体の一部しか映らない時のアバター破綻軽減

## 確認事項(実機未検証)
- 変更はコード解析に基づく修正です。横向き/ミラー環境ではオーバーレイとアバターが実写に一致するか確認ください。
- まだずれがある場合は、どの方向にずれているか（左右反転／90度回転／位置ずれ）と、設定の「向き(回転)」「ミラーを反転」の組み合わせを教えてください。
