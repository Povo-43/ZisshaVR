アバターを「人物の形に切り抜く」のをやめ、**人物の体に合わせて動かす**ように変更しました。

## 主な変更

### 1. 人物マスクによる切り抜きを既定でオフ
- これまでは人物セグメンテーションのシルエットでアバターを切り抜いていたため、
  アバターが「人物の形をした切り抜き」に見えていました。
- 既定を **OFF** に変更し、**アバター全体を人物の位置・大きさに合わせて重ねる**方式にしました。
- 設定 → トラッキング → 「人物の形で切り抜く」で ON に戻せます(人物を完全に隠したい場合)。

### 2. 位置合わせを肩基準に変更(追従の改善)
- アバターの**肩の中点**を、検出した人物の肩の中点に合わせる方式に変更。
  - 肩はほぼ常に見えるため、腰が見切れていても正しく追従します。
  - 腰が見えない場合は、肩の位置から胴の長さぶん下に腰を推定します。
- これにより「中央に固定」「ズレたまま」といった症状を解消します。

### 3. スケールを胴の長さ基準に変更
- これまでは肩幅の比でスケールを決めていましたが、肩幅は「骨の位置」と「服のシルエット」で
  差が出やすく、サイズが合わない原因になっていました。
- **腰(骨)〜肩(骨)の胴の長さ**の比に変更。人物のランドマークもアバターの骨も
  「関節中心どうし」なので、より正確に一致します(肩幅は腰が見えない時のフォールバック)。

### 4. その他
- アバター再読み込み時にユニフォーム位置キャッシュを破棄(別モデルへ切替時の描画乱れ防止)。
- 起動直後から確実に追従を開始するフォールバックを整理(鼻/首→胴長から腰を推定)。

## 期待される動作
- アバターが人物の肩位置・胴の長さに合わせて移動・拡大縮小する(切り抜きなし)
- 人物が動けばアバターも同じように動く
- 人物を完全に隠したい場合は設定の「人物の形で切り抜く」をON
