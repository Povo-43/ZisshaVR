アバター追従パイプラインをしっかり組み直し、「トラッキング時の位置とそうでない位置のチカチカ」を根本から修正しました。

## 修正内容

### 1. ボーンごとの「最後に有効だった向き」を保持（チカチカの根本修正）
従来はポーズ適用のたびに全ボーンの上書きをクリアしていたため、**ランドマークの確信度が1フレームだけ下がる**とその部位がレスト姿勢に戻り、次のフレームで追従位置に戻る…という高速な往復（チカチカ）が発生していました。

- 各ボーンの「最後に有効だったワールド回転」を保持し、データが一時的に欠けたフレームでも**前の向きを維持**するよう変更。
- データがあるボーンだけ毎フレーム上書きし、欠けたボーンは触らない。

### 2. 時系列平滑化（One Euro Filter）を骨ごとに適用
- ルート位置・スケールだけでなく、**四肢・胴・手の回転にも短い時系列平滑化**を適用し、ランドマークのジッタを抑えつつ速い動きには追従。

### 3. スケール推定の安定化
- 胴の長さと肩幅の2通りを切り替えていたためサイズが往復していたのを、**肩幅フォールバックは最初の1回だけ**にし、以降は胴の長さで安定。

### 4. 頭部・手・指は従来の修正を維持
- 顔姿勢変換行列による上下（ピッチ）・手トラッキングのLOD1有効化・左右の取り違え修正はそのまま。

## 期待される動作
- アバターが実写位置とレスト位置の間で行き来しない
- 一部のランドマークが一時的に見えなくても姿勢が保持される
- サイズ・位置が安定し、滑らかに追従する
