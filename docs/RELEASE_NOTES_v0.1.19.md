顔の上下(うなずき)と指の動きを修正しました。

## 1. 顔が上下に動かない → 頭の姿勢をフェイストラッカーから取得
これまで頭の向きは**目の左右位置と目↔口の2D位置**から作っていました。この方法では
**上下(ピッチ)を表現できません**(うなずいても目と口の並びは縦のままのため)。

- MediaPipe FaceLandmarkerの**顔姿勢変換行列(`facialTransformationMatrixes`)**を使い、
  頭ボーンの回転として適用するよう変更。**上下(ピッチ)・左右(ヨー)・首かしげ(ロール)**が
  すべて反映されます。
- 首は回転の35%を負担し、自然な見た目に。
- 顔がしばらく取れない場合のみ従来の目/口ベースにフォールバック(ソース切替のガタつき防止)。

### 併せて修正: 変換行列の格納順
MediaPipeの変換行列は`MatrixData`(既定 **COLUMN_MAJOR**)で列優先です。従来は行優先として
読み込んでいたため**回転が転置(=逆回転)**になっていました(今回の実装で正しく解釈)。

## 2. 指が動かない → 手のトラッキングがLOD2でしか有効でなかった
- 手ランドマークは**LOD 2(人物が近い)時のみ**実行されており、通常のLOD 1では手のデータが
  一切届かず、**指は常に静止**していました。
- **LOD 1から手トラッキングを有効化**しました。

### 併せて修正: 左右の取り違え
MediaPipeのhandednessは**入力画像(ミラー)上の見た目**に対して付きます(ポーズの左右ラベルと
同じ規則)。従来はラベルを反転していたため、**反対の手のランドマークが手ボーンを駆動**し、
腕(ポーズ由来)と手(手トラッカー由来)で左右が食い違って掌が内側を向き、体に刺さる原因に
なっていました。ポーズと同じ規則に統一。

## 期待される動作
- うなずき・首かしげがアバターに反映される
- 指が動き、掌の向きが腕と一致する(体に刺さりにくい)
