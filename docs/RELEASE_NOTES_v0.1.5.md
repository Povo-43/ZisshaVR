アバターが追従しない問題を修正し、カメラの向きを端末ごとに補正できる設定を追加しました。

## 修正

### アバターがT-poseのまま追従しない
- `AvatarController` が `HumanoidRig` を**2つ生成**していました。ポーズは `PoseRigger` 内部のリグに適用される一方、レンダラ(`skinRig`)は別の**ポーズされない**リグからスキン行列を取得していたため、アバターは常に元の姿勢(T-pose)のままでした。
- 修正: `PoseRigger` が持つリグをそのままレンダラ/SpringBoneに使うように統一。
- あわせて v0.1.3 のボーン行列アップロード順の修正(充填前にアップロードしていた問題)により、アバターが表示・変形するようになっています。

### カメラの向き(回転・ミラー)
- 端末の `sensorOrientation` 依存で映像の向きがおかしくなる場合、**設定で補正できるようにしました**。
- 設定 → カメラ → **向き(回転)**: 自動 / 0° / 90° / 180° / 270°
- 設定 → カメラ → **ミラーを反転**: 自動の左右反転を入れ替え
- 回転×ミラーの8通りで、端末による向き・反転のズレを補正できます。
- この向きは**トラッキング入力にも同じ変換**が適用されるため、向きを直すとポーズの精度も改善します。

## 確認事項(実機未検証)
- 変更はコード解析に基づく修正で、実機での確認は未実施です。
- 向きがまだおかしい場合は、設定の「向き(回転)」と「ミラーを反転」を組み合わせて調整してください。
