表情・髪の物理・手のめり込み・動きの滑らかさを修正しました。

## 修正内容

### 1. フェイストラッキング(表情)が動かない問題
- **VRM 0.xの表情名の照合ミス**が原因でした。VRM 0.xの表情グループは仕様上のプリセット名
  (`a`/`i`/`u`/`e`/`o`/`blink`/`joy`…)とは別に、書き出しツール由来の名前(`A`, `Blink` など)を
  持つことがあり、従来はその**生の名前**で照合していたため一致しませんでした。
- 照合を **プリセット名(`presetName`)優先+大文字小文字を無視**に変更。VRM 0.x / 1.0 の
  どちらでも瞬き・口・眉などの表情が反映されます。
- `lookUp/lookDown/lookLeft/lookRight` のプリセット名正規化を追加。

### 2. 髪の毛の物理演算がバグる問題
- スプリングボーンの**レスト方向を「ワールド空間の向き」のまま保持**していたため、実行時に
  現在のワールド行列で変換して**回転が二重にかかり**、髪が逆方向に振れる/暴れる原因に。
- レスト方向を**ボーンのローカル空間**に変換して保持するよう修正。
- VRM 1.0 の**コライダーグループを解決していなかった**ため髪が頭にめり込む問題も修正
  (`VRMC_springBone.colliderGroups` → springs の参照を展開)。
- サブステップ上限を 2→4 に増やし、低フレームレートでも髪が実時間に追従するように。

### 3. 手が身体にめり込む問題
- 手・指のボーンの**レスト方向を「+Y固定」と仮定**していたため、実際のレスト(前腕の続き)
  と最大90°ずれて掌や指が体側へ向いていました。
- リグ自身の**レスト方向(wrist→中指MCP、各指の関節方向)**を使うよう修正。

### 4. 動きが滑らかでない問題
- ルート(位置・スケール)の平滑化を固定係数のlerpから **One Euro Filter** に変更。
  - 静止時はジッタを強く抑え、速い動きでは追従を優先(フレームレート非依存)。
- 位置の目標が「腰検出」⇔「肩から推定」で切り替わるときの段差もフィルタで吸収。

## 期待される動作
- 瞬き・口の開閉・眉・視線などがアバターに反映される
- 髪・スカートが自然に揺れ、頭にめり込まない
- 手のひらの向きが正しく、体に刺さらない
- 移動・拡大縮小が滑らかに追従する
